Post 1,400, and it's a nerdy one! NATS has published its first report into the bank holiday air traffic control meltdown, and it turns out a single flight plan contained two different waypoints that happened to share the same name, which the system couldn't make sense of. Rather than risk passing bad data to controllers, both the main system and its backup shut themselves down, which is exactly why a "failed safe" design still grounded more than a thousand flights. NATS says the situation was about a one-in-fifteen-million event that had never happened before in over fifteen million flight plans, and it has now changed the software so it can't trip over the same thing again. As an infrastructure person, the bit I keep thinking about is that the backup was running the same code and choked on the same input, a great reminder that redundancy only really protects you if your failover can cope with whatever knocked out the primary. Edge cases are where the real dragons live, and I'll be taking that one into work tomorrow. 🐉✈️
